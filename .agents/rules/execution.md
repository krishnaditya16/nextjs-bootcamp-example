# Execution Rules

- **DO NOT** run build commands (`bun run build`, `npm run build`, `next build`, etc.).
- **DO NOT** run lint commands (`bun run lint`, `npm run lint`, `eslint`, etc.).
- **DO NOT** install packages (`bun add`, `npm install`, etc.).
- **DO NOT** use `generate_image` or external image generation tools.
- Write and edit code directly into the workspace files without running background build/test/lint/install scripts.
